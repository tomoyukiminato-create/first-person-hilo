# First Person HiLo PWA（キャッシュアウト判定対応）

正しい的中確率＋端数処理版に、資金管理用のキャッシュアウト判定を追加しました。

## キャッシュアウト条件
判定順序は以下です。

1. 損切りラインに到達 → CASH OUT
2. 利益目標に到達 → CASH OUT
3. 次の最良EVが設定した最低EVを下回る → CASH OUT
4. それ以外 → 続行

## 初期設定
- 開始資金: 100
- 現在資金: 100
- 利益目標: +20%
- 損切り: -20%
- 続行最低EV: 1.000

これらは画面上で自由に変更できます。

## 注意
この機能は「いつ出金すれば必ず勝てるか」を予測するものではありません。
あらかじめ決めた利益目標・損切り・EV基準を機械的に守るための資金管理ツールです。
