# FIRST PERSON HiLo PWA

GitHub Pages へ `first-person-hilo-pwa` フォルダ内のファイルをそのままアップロードしてください。

- 13ランク（2〜A）を等確率として計算
- LOWER / SAME: 現在ランク以下
- HIGHER / SAME: 現在ランク以上
- 期待値 = 的中確率 × 配当倍率 − 1
- 純利益 = 次の賭け金 × (配当倍率 − 1)
- iPhoneホーム画面追加対応
- オフラインキャッシュ対応


## PC対応
- Windows / macOS の Chrome・Edge などで利用可能
- 画面幅1000px以上ではPC向け2カラムレイアウト
- カード選択は13ランクを横1列に表示
- スマートフォン表示は従来レイアウトを維持
- 対応ブラウザではPWAとしてデスクトップへインストール可能


## v5 自動倍率入力
- 「現在の掛け金」と「次に当てたときの掛け金」から掛け金倍率を自動計算
- 掛け金倍率 = 次の掛け金 ÷ 現在の掛け金
- 自動入力ON時、その倍率を LOWER / SAME と HIGHER / SAME の両方へ自動反映
- 自動入力OFFにすると、LOWER / HIGHERを個別に手入力可能

例：現在 1,000円、次回 1,500円 → 1.50倍 → LOWER 1.50 / HIGHER 1.50


## v6 当選金から倍率を自動入力
- 現在の掛け金を1か所入力
- LOWER / SAME の当選金を入力
- HIGHER / SAME の当選金を入力
- LOWER倍率 = LOWER当選金 ÷ 現在の掛け金
- HIGHER倍率 = HIGHER当選金 ÷ 現在の掛け金
- 自動入力OFFでは倍率を手動入力可能

例:
- 現在の掛け金 1,000円
- LOWER当選金 2,100円 → LOWER 2.10倍
- HIGHER当選金 1,600円 → HIGHER 1.60倍
