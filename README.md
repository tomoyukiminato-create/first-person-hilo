# First Person HiLo キャッシュアウト判定 PWA

`index.html` を含むフォルダを HTTPS 対応の静的ホスティングに配置してください。ローカルでは `python3 -m http.server 8000` をこのフォルダで起動し `http://localhost:8000/` で開けます。iPhone では Safari の共有メニューから「ホーム画面に追加」を選択できます。PWA のオフライン利用は HTTPS または localhost で一度読み込んでから有効になります。

現在のカードと現在の確定受取額、HIGH/LOW 成功時の受取総額を入力します。次のカードを毎回独立に抽選し、13ランクが等確率、同値を両方向の的中に含める前提です。HIGH 確率 `(13-index)/13`、LOW 確率 `(index+1)/13`（index は2を0、Aを12）。期待受取額は `確率×成功時受取総額`。同率で確定額を超えない場合はキャッシュアウトを表示します。失敗時の受取は0です。ベット後の追加手数料や次の次の意思決定は評価していません。

実際のゲームの同値処理やカードの独立性、表示される受取額が違う場合、この計算結果は適用できません。特に過去の説明にある「7のHIGH = 7/13」は、2〜Aで同値を含める設定では誤りで、正しくは8/13です。
