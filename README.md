# First Person HiLo PWA — 式の近似版

この版は、52枚のカード枚数を直接数えるのではなく、
カードランクを使った近似式で的中確率を計算します。

## 近似式

カードランク：
- A = 1
- 2〜10 = 2〜10
- J = 11
- Q = 12
- K = 13

計算式：
- HIGH = (14 - ランク) / 13
- LOW = (ランク - 1) / 13

### 例：7
- LOW = (7 - 1) / 13 = 6/13 = 46.153846...%
- HIGH = (14 - 7) / 13 = 7/13 = 53.846153...%

## EV
EV = 的中確率 × 払戻し倍率

## 端数処理
- 倍率表示：小数2 / 3 / 4桁
- 払戻し額：切り捨て / 四捨五入 / 切り上げ
- 通貨最小単位：1 / 0.1 / 0.01

## 注意
これはランク差を使った近似モデルです。
Evolution First Person HiLo の公式ルールを52枚ベースで厳密に再現する版とは異なります。
