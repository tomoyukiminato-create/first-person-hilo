# First Person HiLo PWA — 正確な的中確率版

Evolution公式ルールに合わせ、的中確率を52枚のカード枚数から直接計算します。

## 確率
毎回、新しい52枚デッキから次のカードが配られる前提です。各ランクは4枚です。

- 3〜K
  - Lower or Same: 2〜現在カード
  - Higher or Same: 現在カード〜A
- 2
  - Same: 4/52 = 7.692307...
  - Higher: 48/52 = 92.307692...
- A
  - Lower: 48/52 = 92.307692...
  - Same: 4/52 = 7.692307...

### 7の例
- Lower or Same: 2,3,4,5,6,7 = 6ランク × 4 = 24/52 = 46.153846...%
- Higher or Same: 7,8,9,10,J,Q,K,A = 8ランク × 4 = 32/52 = 61.538461...%

Sameが両方の通常選択肢に含まれるため、2つの的中確率の合計は100%を超えます。これは仕様上正しいです。

## EV
EV = 的中確率 × 払戻し倍率

内部計算では確率・倍率を丸めません。画面表示と払戻し表示だけ端数処理します。
