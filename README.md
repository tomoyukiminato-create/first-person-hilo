# FIRST PERSON HiLo PWA

GitHub Pages へ `first-person-hilo-pwa` フォルダ内のファイルをそのままアップロードしてください。

- 13ランク（2〜A）を等確率として計算
- LOWER / SAME: 現在ランク以下
- HIGHER / SAME: 現在ランク以上
- 期待値 = 的中確率 × 配当倍率 − 1
- 純利益 = 次の賭け金 × (配当倍率 − 1)
- iPhoneホーム画面追加対応
- オフラインキャッシュ対応


## PC対応
- Windows / macOS の Chrome・Edge などで利用可能
- 画面幅1000px以上ではPC向け2カラムレイアウト
- カード選択は13ランクを横1列に表示
- スマートフォン表示は従来レイアウトを維持
- 対応ブラウザではPWAとしてデスクトップへインストール可能


## v5 自動倍率入力
入力するのは以下です。
- 現在の掛け金
- LOWER 当選金（総払戻額）
- HIGHER 当選金（総払戻額）

倍率は自動で `当選金 ÷ 現在の掛け金` として計算されます。
例: 掛け金1,000円 / LOWER当選金2,100円 → 2.10倍。
