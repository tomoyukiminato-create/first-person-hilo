# FIRST PERSON HiLo PWA

GitHub Pages にそのまま配置できる静的PWAです。

## GitHub Pages
1. リポジトリ直下にこのフォルダ内のファイルをアップロード
2. Settings → Pages
3. Deploy from a branch
4. main / (root) を選択
5. iPhoneのSafariで公開URLを開く
6. 共有 → ホーム画面に追加

## 主な機能
- 2〜Aの現在カード選択
- HIGHER / SAME、LOWER / SAME の確率
- 配当倍率入力
- 賭け金倍率の自動計算
- EV計算
- 推奨判定
- 履歴 / 統計 / 設定
- localStorage保存
- オフラインPWA
