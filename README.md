# First Person HiLo PWA — 無限デッキ・動的判定版

判定結果が計算値に応じてリアルタイムに切り替わるよう修正しました。

## 判定ルール
- LOW側・HIGH側の両方がマイナス期待値 → NO BET
- LOW側の期待値が高い → LOW側を表示
- HIGH側の期待値が高い → HIGH側を表示
- 両方の期待値が同じ → 同率
- 片側だけ入力されている場合 → その側だけで判定

## 色
- LOW側推奨 → 青系
- HIGH側推奨 → 赤系
- NO BET → グレー系
- 同率 → 黄系

## 無限デッキ確率
各ドローは独立で、2〜Aの13ランクが毎回それぞれ1/13です。
過去カードは確率に影響しません。
