# First Person HiLo PWA — 正確な期待値版

## 的中確率
52枚・各ランク4枚として直接計算します。

- 3〜K: Lower or Same / Higher or Same
- 2: Same / Higher
- A: Lower / Same

例：7
- Lower or Same = 24/52 = 46.153846...
- Higher or Same = 32/52 = 61.538461...

## 正確な期待値
払戻し倍率を「賭け金を含む総払戻し倍率」として扱います。

- 期待払戻し率 = 的中確率 × 払戻し倍率
- 期待純利益 = 期待払戻し率 - 1
- 損益分岐倍率 = 1 / 的中確率

例：
的中確率 0.615384615...、払戻し倍率 1.86 の場合
- 期待払戻し率 = 0.615384615... × 1.86 = 1.144615384...
- 期待純利益 = +0.144615384...

つまり1単位賭けたときの理論上の平均純利益は +0.144615... 単位です。

## 判定
- 両方の期待純利益がマイナス → NO BET
- 片方または両方がプラス → より期待純利益の高い側を表示

内部計算では丸めません。
