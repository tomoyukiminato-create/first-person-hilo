# FIRST PERSON HiLo 判定計算ツール

画像のレイアウトを参考にしたPWAです。

## 機能
- 現在カード 2〜A を選択
- 共通の賭け金を1か所に入力
- LOWER / SAME 当選金、HIGHER / SAME 当選金を入力
- 払戻倍率を自動計算
- 的中確率を52枚デッキ基準で表示
- 正確な比率（例 20/52 = 5/13）を表示
- 期待値を自動計算
- 的中時純利益を表示
- 期待値が高い側を自動推奨
- スマホ / PC 両対応
- PWAインストール / オフライン対応

## 計算式
- 払戻倍率 = 当選金 ÷ 賭け金
- 期待値 = 的中確率 × 払戻倍率 − 1
- 純利益 = 当選金 − 賭け金
