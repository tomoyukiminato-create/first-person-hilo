# First Person HiLo PWA — 無限デッキ版

## 無限デッキモデル
各ドローは独立です。
2〜Aの13ランクが毎回それぞれ 1/13 の確率で出るものとして計算します。
過去に出たカードは一切減算しません。

## 的中確率

### 3〜K
- Lower or Same = 2〜現在カードのランク数 / 13
- Higher or Same = 現在カード〜Aのランク数 / 13

### 2
- Same = 1/13 = 7.692307...
- Higher = 12/13 = 92.307692...

### A
- Lower = 12/13 = 92.307692...
- Same = 1/13 = 7.692307...

### 例：7
- Lower or Same = 6/13 = 46.153846...
- Higher or Same = 8/13 = 61.538461...

## 期待値
- 期待払戻し率 = 的中確率 × 払戻し倍率
- 期待純利益 = 期待払戻し率 - 1
- 損益分岐倍率 = 1 / 的中確率

内部計算では丸めません。
