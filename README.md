# First Person HiLo PWA（端数処理対応版）

正しい的中確率版をベースに、倍率・払戻しの端数処理を追加したPWAです。

## 端数処理の考え方
Evolution公式は、各選択肢に表示される payout offer が「before rounding（丸め前）」であると説明しています。
そのためこのPWAでは：

- 的中確率：内部では丸めず計算
- 倍率：内部では丸めず保持
- EV：丸め前の確率 × 丸め前の倍率で計算
- 倍率の画面表示：小数2 / 3 / 4桁を選択
- 払戻し額：切り捨て / 四捨五入 / 切り上げを選択
- 通貨の最小単位：1 / 0.1 / 0.01 を選択

初期設定は「倍率 小数2桁」「払戻し 切り捨て」「最小単位 1」です。
カジノ・通貨によって実際の残高処理が異なる場合は設定を合わせてください。

## 的中確率
- 通常（3〜K）：Lower or Same / Higher or Same
- 2：Same / Higher
- A：Lower / Same
- 次のカードは毎回新しい52枚デッキから配られる前提

例：7
- Lower or Same = 24/52 = 46.153846...%
- Higher or Same = 32/52 = 61.538461...%
