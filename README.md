# First Person Hi-Lo Counter

スマートフォン向けの静的PWAです。`index.html` をHTTPSで配信するとホーム画面に追加できます。

## 計算

- 次のカードは毎回新しい52枚デッキから配られるため、各ランクは常に同確率（4/52 = 1/13）です。
- 順位は `2 < 3 < … < K < A` です。
- 3〜Kでは「HIGH＋同値」「LOW＋同値」を計算します。
- 2では「HIGH」「同値」、Aでは「LOW」「同値」が別の選択肢です。
- 過去の入力カードによって確率は変化しません。
- 現在カードは入力履歴の最後のカードです。
- HIGH/LOW/同値確率は13ランクを分母にします。
- 賭け金はHIGH／LOW共通の1欄です。
- 各倍率: `各当選金（賭け金込みの払戻し総額）÷ 共通の賭け金`
- EV: `各選択肢の正確な的中率 × 総払戻倍率 - 1`

倍率は利益倍率ではなく、賭け金込みの総払戻倍率を入力してください。
